## 📓 观测记录 #001

> 2026 年 10 月 30 日，深夜。观测员向国内 5 家 AI 问了一句话。

```
你：     苏州当地有哪些医美

平台 A： （悄悄看了一眼你浏览器的定位权限）
平台 B： （先去查了你的 IP —— 苏州市，江苏省）
平台 C： （掏出一个叫 region_search 的工具）

平台 A： 我替你搜 5 句：
         ……敏感肌……避坑……红血丝……
         ……还有你上一个问题聊过的那个品牌

平台 B： 我只搜 1 句就够了
平台 D： 我搜 3 句，记得带上「2025」

平台 E： （下一个问题，开深度思考）
         我搜一轮，打开 7 个网页；再搜一轮，再打开 3 个。
         第二轮，我已经在查某家医院的某台仪器了。

你：     ……我就问了一句话啊
```

**观测员笔记：** 你看到第一个字之前，AI 已经替你做了三个决定。

1. **你在哪**
2. **去搜什么**
3. **信谁**

每一家，做法都不一样。

## 🧪 我们怎么看

| 步骤 | 干什么 |
|---|---|
| **观察** | 手动提问，把请求、响应、搜索词、引用、token 一条条抓下来 |
| **分析** | 同一个问题，五家放在一起看 |
| **消融** | 一次只改一个变量：开关联网、等长对照、换干净账号、放一个受控网页等 AI 来看 |

每条结论都会挂上一个灯：

- 🟢 **实测**：亲眼看见的，至少重复两轮
- 🟡 **推断**：从数据推出来，像福尔摩斯，但没有直接证据
- 🔴 **猜想**：先记下来，等着被证实，或者被打脸
